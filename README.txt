COLLEGE BUS PASS MANAGEMENT - NO LOCALHOST VERSION

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the frontend folder.
3. Double-click index.html. It opens directly in your browser.
4. Do not run run.bat. No Java server, localhost, or backend is used.

DATA STORAGE:
Student records and bus pass records are saved in browser localStorage.
They remain after closing and reopening the same browser on the same computer.
Do not clear browser site data or use private/incognito mode if you want to keep records.
Data is browser/device-specific and is not automatically shared with other computers.

HOW TO USE:
1. Register a student using Student ID, name and department.
2. Issue a pass using that registered Student ID, bus number, route, start date and end date.
3. Search by student ID, student name, bus number, or pass ID (example: BP101).
4. Click the refresh button to show all saved passes again.

No localhost, no server, no notifications.
